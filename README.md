# Taskboard — Collaborative Project Management Platform

A Trello-style collaborative task board built with React, Express, and MongoDB. Create boards, organize work into lists, manage cards with drag-and-drop, assign teammates, set due dates, and comment on tasks in real time.

## Features

- Email/password authentication with JWT
- Create, rename, and delete boards
- Invite teammates to boards by email
- Lists and cards with full CRUD
- Drag-and-drop reordering (lists and cards, including across lists)
- Card details: description, due date, assignee, comments
- Owner-only board settings

## Tech stack

**Frontend:** React, React Router, Tailwind CSS v4, Axios, @hello-pangea/dnd
**Backend:** Node.js, Express, MongoDB (Mongoose), JWT, bcrypt
